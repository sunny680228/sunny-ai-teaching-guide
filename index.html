02 / AI 和老師的關係

老師掌握方向，AI 協助展開。

◎

教師的專業判斷

讀懂學生、決定學習目標、選擇教材重點，並根據課堂反應調整提問與鷹架。

  • 這個活動要讓學生學會什麼？
  • 學生的回答，有哪些理解與迷思？
  • 哪些內容適合現在的學習階段？
✧

AI 的協作支援

協助整理資訊、生成不同方案、製作互動素材與檢查初稿，讓教師更容易比較、選用與修正。

  • 同一目標，可以怎麼教？
  • 能提供哪些提問、例子與提示？
  • 能把既有設計做成什麼工具？
目標由教師決定 → AI 提出方案 → 教師選用修正 → 從學生表現再調整

03 / 課中教學・康軒四上〈我的籃球夢〉

從讀懂故事，
到寫出自己的成長。

以倒敘法為讀寫連結，讓孩子從排序、找線索、說理由，走向「我學會了＿＿」的真實經驗書寫。

本課學習重點

順敘與倒敘

認識倒敘法的安排與效果，並運用在自己的記敘文中。

要看見的學習證據

能用文本線索說明敘事順序，指出角色心情變化的依據，並用成功畫面開頭、回溯學習歷程。

課堂的五個步驟

先讓學生思考，再讓工具協助。

讀出寫法 / 比較兩種鏡頭

同一段經歷，換個開頭會怎樣？

以下用學習經驗示意敘事結構，並非課文段落原文。

順敘：跟著事情往前走

  1. 開始接觸籃球
  2. 遭遇挫折，接受協助
  3. 反覆練習，逐漸進步
  4. 投籃成功，分享收穫

適合觀察：事情如何一步一步發生？

倒敘：先看見成功的一刻

  1. 成功畫面，吸引讀者
  2. 回到起點，交代原因
  3. 回顧挫折、協助與練習
  4. 回到現在，寫下體會

追問：讀完開頭，你會想知道什麼？

讀寫結合 / 我學會了＿＿

把課文的寫法，帶進自己的故事。

從自身真實經驗選材，依序完成審題、九宮格取材、倒敘大綱，再進入寫作與分享。
